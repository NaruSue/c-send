# c-send 接続先定義・ニュース仕様 v1

公式PWA公開定義: `https://narusue.github.io/c-send.pwa/connections.json`（互換URL: `https://loose.bz/c-send/pwa/connections.json`）

## 接続先定義

ルートは `format: "c-send-connections"`、`version: 1`、`connections: []`。
同梱の connections.json が公式ポータルの実例。PWA が定義を読み込み、共通の接続先詳細を生成する。

各接続先:

| フィールド | 内容 |
| --- | --- |
| id | 重複しない固定ID。変更すると既読や端末設定との関連が切れる |
| name | 接続先一覧・絞り込み・お知らせに表示する名前 |
| baseUrl | HTTPS のサイト基準URL。末尾 `/` を推奨 |
| apiBaseUrl | API基準URL |
| color | `#RRGGBB`。利用者の端末側で変更可能 |
| capabilities | account / templateSync / backup / news の真偽値 |
| auth.type | 認証方式の識別子 |
| news.url | baseUrlと同じオリジンのHTTPSニュースURL |
| menu | account / syncSettings / siteLink の順序付き配列 |

メニューの `label` は表示名、`requiresLogin` はログインを必要とする項目。
`siteLink.path` はbaseUrlから解決し、同じオリジンのみを許可する。
JSONは実行コードや認証情報を含めない。未知のメニュー種別は表示しない。

### 現行クライアントの対応範囲

0.1.66の保存・認証・バックアップ用アダプターは公式ポータル用。
外部サイトの保存・認証機能はJSONだけで動作するわけではなく、今後対応アダプターと認証仕様の整備が必要。
現在は第三者サイトに `templateSync: true` を指定すると定義を拒否する。
Google Driveへの直接接続は未実装。

第三者サイトのお知らせと通常のサイトリンクは同じ定義形式で扱える。
外部サイトのニュースはPWAオリジン `https://loose.bz` からのCORS読み取りを許可すること。
現在の接続先追加は配信するconnections.jsonの編集で行う。任意URLの登録画面は未実装。
公式ポータルの特別扱いは同梱定義の固定IDと固定APIの組み合わせでのみ有効。

## ニュース取得

公開GET。認証・Cookie不要。JSONレスポンス:

```json
{
  "format": "c-send-news",
  "version": 1,
  "releases": [
    {
      "id": "release-001",
      "title": "お知らせのタイトル",
      "body": "プレーンテキスト本文",
      "published_at": "2026-11-04T09:00:00+09:00"
    }
  ]
}
```

既存ポータル互換のため `format` と `version` がないレスポンスも受理する。
idは配信元内で固定・一意にし、published_atはタイムゾーン付きISO 8601で返す。
titleと公開日時のない項目、未来の公開日時の項目は表示しない。
body未指定時はsummaryを利用可能。HTMLやスクリプトは実行しない。
各サイトが返した項目をアプリ側で統合し、公開日時の降順で表示する。
現行クライアントは指定URLの1レスポンスを読む。初期仕様ではページ送りなし。サーバーで最新30件程度を返すことを推奨。
ETag/Last-ModifiedとCache-Controlは配信側で設定可能。現行クライアントは明示更新を優先してno-storeで取得する。
エラー時はHTTP 4xx/5xxを返す。失敗した配信元は前回取得分を表示し、他の配信元の取得は続ける。

アプリのお知らせは `news.json` に同形式で置く。接続先の有効・無効とは独立する。
既読キーは `接続先ID:ニュースID`。アプリの配信元IDは `app`。

## 端末側の情報

接続先の有効状態・利用者が選んだ色は端末ごとに保存し、配信定義と分離する。
既存の公式接続は初期状態で有効。無効にしてもログイン情報やテンプレートを削除しない。
公式保存項目にはconnectionIdを付与し、従来のsiteId・リビジョン・競合処理を維持する。
端末内項目は接続先を持たない。公式サンプルとURL参照は保存先とは別の参照元として管理する。
一覧の接続先表示は色だけで行い、配信元名ラベルを挿入しない。正式名称は編集・参照詳細で確認できる。
絞り込みは保存先・参照元を一つ、通常タグを複数ANDで選択する。
次に選べるタグは現在の結果に含まれるものだけ。選択済みタグは解除用に保持する。
選択状態は端末ごとに保存し、キャッシュ読み込み後に存在しない選択を除去する。

## 公式ポータルのトップメニュー導線

「お知らせ」の直下に「公式サイト」「テンプレート管理」を表示する条件:
公式接続が有効、navigator.onLineが真、公式ニュースAPIが正常なJSONを返すこと。
起動・メニューを開く時・画面復帰・ネット復帰時に確認する。オフライン時は即座に非表示。
ログイン状態を表示条件には含めない。プロフィール設定は接続先内のみ。

## 公式アカウントと補助機能（2026-11-05）

0.1.84時点では公式接続先 `official-portal` の `c-send-pkce-v1` アカウントだけを、隠し機能の端末内個人記録に使用する。他の接続先は対象外。
接続先としての有効・無効と、保存済み認証情報の有無は別の状態であり、無効化だけでログアウト・記録削除はしない。
アカウントと同期設定は、接続先一覧から開いた場合に閉じる操作で同一覧へ戻る。
詳細は [PWA保守記録](../../docs/pwa-easter-egg.md)。診断は既存の公式アカウント管理者パネルから手動送信する。
バージョンアップ時の旧診断ログ消去は [次回更新項目](../../docs/pwa-next-update.md) に記載し、現行PWAで実装済み。
