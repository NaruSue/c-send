# はじめて使う人へ

このページでは、c-sendで文章を登録して、あとから呼び出す方法を説明します。

## c-sendでできること

c-sendは、よく使う文章やコマンドを登録しておく箱です。
登録したものを選ぶと、すぐに貼り付けて使えます。

たとえば、次のようなものを登録できます。

- メールの返事
- チャットで使うあいさつ
- Webサイトの住所（URL）
- コマンド
- SQL

## 1. c-sendを起動する

1. `csend.exe`をダブルクリックします。
2. c-sendの画面が開きます。

画面が見つからない場合は、画面の右下にあるタスクトレイのc-sendアイコンをクリックしてください。

## 2. 文章を登録する

1. 画面の一覧のいちばん下にある「（追加）」を選びます。
2. 文章の名前を入力します。

   例: `会議のお礼`

3. 使いたい文章を入力します。

   例:

   ```text
   本日は会議のお時間をいただき、ありがとうございました。
   ```

4. 「保存」を押します。

これで登録完了です。

## 3. 登録した文章を使う

1. c-sendの一覧から、先ほど登録した名前を選びます。
2. 文章がクリップボードへコピーされます。
3. メールやチャットを開きます。
4. `Ctrl`キーを押しながら`V`キーを押します。

登録した文章が貼り付けられます。

## 4. 文章を分けて整理する

文章が増えたら、カテゴリに分けると探しやすくなります。

1. システムメニューから「カテゴリ」を開きます。
2. 一覧のいちばん下にある「（追加）」を選びます。
3. カテゴリの名前を入力します。

   例: `メール`

4. 文章を保存するファイルの名前を入力します。

   例: `mail.json`

5. 「保存」を押します。
6. 追加したカテゴリを選びます。
7. 一覧の「（追加）」から文章を登録します。

## 5. サンプルを使う

最初から文章を作るのが大変な場合は、同梱サンプルを使えます。

カテゴリ設定で、次のファイルを指定してください。

```text
samples\jp\メール・チャット.json
```

ほかにも、次のサンプルがあります。

- `samples\jp\挨拶.json`
- `samples\jp\Git.json`
- `samples\jp\SQL.json`
- `samples\jp\PowerShell.json`
- `samples\jp\Windowsコマンド.json`

## 困ったとき

- 文章を選んでも貼り付けられない場合は、貼り付け先をクリックしてからもう一度`Ctrl`+`V`を押します。
- 文章が見つからない場合は、画面上部のカテゴリを確認します。
- c-sendの画面が見つからない場合は、タスクトレイのアイコンをクリックします。
- サンプルが読み込めない場合は、`samples`フォルダが`csend.exe`と同じ場所にあるか確認します。

AIを使った要約や添削を試したい場合は、別の[Geminiと連携してみる](api/gemini-tutorial.md)チュートリアルを参照してください。
