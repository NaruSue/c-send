# c-send テンプレート記法仕様

この文書は、`mode` が `template` の項目で使用するテンプレート記法を定義する。

## 1. 基本構文

テンプレート内の置換箇所は、`{{` と `}}` で囲む。

```text
{{command(param1,param2)}}
```

- `command` は実行するコマンド名
- 引数は `(` と `)` の中に記述する
- 引数はカンマで区切る
- 文字列は半角ダブルクォートで囲む
- `current` などの予約語はクォートしない
- `{{`、`}}` の内側の先頭と末尾の空白は無視する
- コマンド名や引数の途中にある空白は、各コマンドの仕様に従う

例:

```text
作業日：{{date("yyyy/MM/dd",current)}}
```

## 2. 日付・時刻

### 2.1 `date`

`date` は、基準日時に差分を加減算し、指定した書式で出力する。

```text
{{date()}}
{{date("format",current)}}
{{date("format",current,"offset")}}
```

引数は次の順序とする。

```text
date(表示形式,基準日時,差分)
```

| 引数 | 必須 | 内容 |
| --- | --- | --- |
| `表示形式` | 任意 | 出力する日付・時刻の書式。省略時は `yyyy/MM/dd HH:mm:ss` |
| `基準日時` | 任意 | 計算の基準。現在は `current` を使用する。省略時は現在日時 |
| `差分` | 任意 | 基準日時からの加算・減算。省略時は差分なし |

### 2.2 日付・時刻の書式

書式文字列は次の記号を使用する。

| 記号 | 内容 | 例 |
| --- | --- | --- |
| `yyyy` | 4桁の年 | `2024` |
| `MM` | 2桁の月 | `12` |
| `dd` | 2桁の日 | `22` |
| `HH` | 24時間制の時 | `09` |
| `mm` | 分 | `05` |
| `ss` | 秒 | `30` |

`MM` は月、`mm` は分を表す。大文字と小文字を区別する。

例:

```text
{{date("yyyy/MM/dd",current)}}
```

```text
2024/12/22
```

```text
{{date("yyyy/MM/dd HH:mm",current)}}
```

```text
2024/12/22 09:30
```

### 2.3 日付・時刻の差分

差分は、符号と単位を組み合わせて指定する。

| 単位 | 内容 |
| --- | --- |
| `s` | 秒 |
| `m` | 分 |
| `h` | 時間 |
| `d` | 日 |
| `w` | 週 |

例:

```text
{{date("yyyy/MM/dd",current,"+7d")}}
```

現在日時の7日後を出力する。

```text
{{date("yyyy/MM/dd",current,"-1d")}}
```

現在日時の1日前を出力する。

```text
{{date("HH:mm",current,"+100m")}}
```

現在時刻の100分後を出力する。

```text
予定日時：{{date("yyyy/MM/dd HH:mm",current,"+1w")}}
```

## 3. クリップボードの操作

### 3.1 `clipboard`

`clipboard` は、現在のクリップボードの内容をそのままテンプレートへ差し込む。

```text
{{clipboard}}さん
```

クリップボードの内容が `加藤` の場合、出力は次のようになる。

```text
加藤さん
```

共通仕様:

- クリップボードの内容を変更せず、そのまま差し込む
- 複数行の内容もそのまま差し込む
- クリップボードが空の場合は空文字として扱う

### 3.2 `sort`

`sort` は、現在のクリップボードの内容を改行単位で分割し、昇順に並べ替えて出力する。

```text
{{sort}}
```

入力:

```text
zebra
apple
melon
```

出力:

```text
apple
melon
zebra
```

### 3.3 `sort_desc`

`sort_desc` は、現在のクリップボードの内容を改行単位で分割し、降順に並べ替えて出力する。

```text
{{sort_desc}}
```

入力:

```text
apple
melon
zebra
```

出力:

```text
zebra
melon
apple
```

### 3.4 共通仕様

- ソート対象は現在のクリップボードの内容とする
- 行単位でソートする
- ソート後の結果をテンプレートの出力値とする
- CSVの列単位ソートや数値としてのソートは、本仕様では定義しない
- 空のクリップボードや読み込みエラーの扱いは、実装側のエラー処理に従う

### 3.5 `calc`

`calc` は、現在のクリップボードの内容を単純な数式として評価し、計算結果を出力する。

```text
{{calc}}
```

入力:

```text
(2-3)*12+56
```

出力:

```text
44
```

初期実装で対応する数式は次のとおりとする。

- 数値
- 小数
- 加算 `+`
- 減算 `-`
- 乗算 `*`
- 除算 `/`
- 括弧 `(` `)`
- 式中の空白

次の機能は本仕様の対象外とする。

- 変数
- 関数
- 代入
- 複数行の数式
- 単位変換

0による除算、不正な文字、括弧の不一致など、数式を評価できない場合はテンプレートエラーとして扱う。

### 3.6 `json`

`json` は、現在のクリップボードの内容をJSONとして解析し、人が読みやすい整形済みJSONを出力する。

```text
{{json}}
```

入力:

```json
{"name":"c-send","items":[1,2,3]}
```

出力:

```json
{
  "name": "c-send",
  "items": [
    1,
    2,
    3
  ]
}
```

共通仕様:

- インデントは半角スペース2個とする
- オブジェクトのキーの順序は変更しない
- JSONの値や構造は変更しない
- JSON文字列内の改行やエスケープはJSON仕様に従って扱う
- JSONとして解析できない場合はテンプレートエラーとして扱う

### 3.7 `uri_encode` / `uri_decode`

`uri_encode` は、現在のクリップボードの内容をUTF-8のURI文字列としてパーセントエンコードする。
`uri_decode` は、パーセントエンコードされたURI文字列を元の文字列へ戻す。

```text
{{uri_encode}}
{{uri_decode}}
```

入力:

```text
東京駅 A&B
```

`{{uri_encode}}` の出力:

```text
%E6%9D%B1%E4%BA%AC%E9%A7%85%20A%26B
```

共通仕様:

- エンコード対象は現在のクリップボード全体とする
- 文字コードはUTF-8とする
- 空白は`%20`としてエンコードする
- URL全体の解析や、`https://`、パス、クエリの分割は行わない
- 不正なエンコード文字列をデコードできない場合はテンプレートエラーとして扱う

## 4. テンプレートの例

```text
障害発生日時：{{date("yyyy/MM/dd HH:mm",current)}}
暫定対応期限：{{date("yyyy/MM/dd HH:mm",current,"+2h")}}
次回確認日：{{date("yyyy/MM/dd",current,"+1d")}}
```

## 5. エラー時の扱い

- 未定義のコマンドは置換せず、テンプレートエラーとして扱う
- 引数の数や形式が不正な場合はテンプレートエラーとして扱う
- 不正な日付書式や差分はテンプレートエラーとして扱う
- テンプレートエラー時に、エラー内容を含んだ文字列を送信してはならない

## 6. 対象外

次の機能は本仕様では定義しない。必要になった時点で別途追加する。

- 2つの日付の差分を求める処理
- 営業日・祝日を考慮した日付計算
- タイムゾーンの変換
- テンプレート内のコマンドの入れ子
