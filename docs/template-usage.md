# c-send テンプレートの使い方

テンプレートを使うと、定型文をコピーする直前に日時やクリップボードの内容を埋め込めます。

## テンプレート項目を作成する

1. `.json` のカテゴリを作成または選択します。
2. メニューから「文字列の登録」を選びます。
3. タイトルと本文を入力します。
4. 本文入力欄の下で `template` を選びます。
5. `OK` を押して保存します。

一覧では、テンプレート項目のタイトルに `[T]` が付きます。

## 基本の書き方

テンプレート内の `{{` と `}}` で囲んだ部分が、コピー時に置き換わります。

```text
作成日：{{date("yyyy/MM/dd",current)}}
```

例えば次のように使えます。

```text
お疲れさまです。
本日の作業日：{{date("yyyy/MM/dd",current)}}
```

`{{` と `}}` の内側の前後にある空白は無視されます。文字列の引数は半角ダブルクォートで囲みます。

## 使用できるコマンド

### 日時を入れる: `date`

```text
{{date()}}
{{date("yyyy/MM/dd",current)}}
{{date("yyyy/MM/dd HH:mm",current,"+2h")}}
```

引数は「表示形式、基準日時、差分」の順です。基準日時には `current` を指定します。

使用できる書式は次のとおりです。

- `yyyy`: 年4桁
- `MM`: 月2桁
- `dd`: 日2桁
- `HH`: 時刻（24時間制）
- `mm`: 分
- `ss`: 秒

差分の単位は `s`（秒）、`m`（分）、`h`（時間）、`d`（日）、`w`（週）です。

```text
提出期限：{{date("yyyy/MM/dd HH:mm",current,"+1d")}}
```

### クリップボードを入れる: `clipboard`

```text
{{clipboard}}さん、こんにちは。
```

コピー時点のクリップボードの内容が、そのまま挿入されます。複数行の内容にも対応します。

### 行を並べ替える: `sort` / `sort_desc`

クリップボードの内容を改行ごとに分割し、昇順または降順に並べ替えます。

```text
{{sort}}
```

```text
{{sort_desc}}
```

### 計算する: `calc`

クリップボードの数式を計算します。

```text
{{calc}}
```

対応する演算子は `+`、`-`、`*`、`/` と括弧です。例えばクリップボードに `(2-3)*12+56` がある場合、`44` になります。

### JSONを整形する: `json`

クリップボードのJSONを2スペースのインデントで整形します。

```text
{{json}}
```

JSONとして正しくない内容はコピーできません。

### URIエンコード・デコード: `uri_encode` / `uri_decode`

```text
{{uri_encode}}
{{uri_decode}}
```

`uri_encode` はUTF-8のパーセントエンコードを行い、`uri_decode` は元の文字列へ戻します。空白は `%20` になります。

## 注意事項

- テンプレートは項目をクリックしてコピーするときに評価されます。本文そのものは保存時に置き換わりません。
- URLカテゴリは読み取り専用のため、テンプレート項目を編集できません。
- 従来の3行形式のデータファイルでは、テンプレート情報を保存できません。
- コマンド名、引数、日時書式が正しくない場合はエラーになり、内容はコピーされません。
- `counter` は将来用の予約値で、現在の登録画面では選択できません。

詳細な記法は [テンプレート記法仕様](./template-spec.md) を参照してください。
