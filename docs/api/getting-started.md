# API利用者向け導入手順

このページは、c-sendでGeminiやOpenAIなどのAPIを利用したい人向けの手順です。

通常の定型文・テンプレート機能だけを使う場合、この手順は必要ありません。

## 1. API設定JSONを用意する

API設定JSONは、利用したいAPIの公式資料とc-sendの仕様書をAIへ渡して作成できます。

次の2つをAIへ渡してください。

- [API設定JSON仕様](./config-spec.md)
- 利用したいAPIの公式ドキュメント、または公式URL

次のように依頼します。

```text
添付したc-send API設定JSON仕様に従って、API設定JSONと導入手順を作成してください。

対象API: （APIサービス名）
利用したい機能: （例: 文章を要約する、天気を取得する）
公式ドキュメント: （URLまたは添付資料）
```

AIにはAPIキー、token、ID、PASSの実際の値を送らないでください。

## 2. JSONを配置する

AIが出力したJSONコードブロックの内容だけを、次の場所へUTF-8のJSONファイルとして保存します。

```text
csend.exeと同じフォルダ\api\<設定ID>.json
```

`api`フォルダがない場合は作成してください。Markdownのコードフェンス（```jsonなど）は保存しません。

保存後、c-sendを再起動します。

## 3. APIの設定を確認する

1. タスクトレイのc-sendアイコンからシステムメニューを開きます。
2. 「API」を開き、追加したAPIとActionが表示されることを確認します。
3. API詳細画面で、認証方式とクレデンシャルIDを確認します。

Open-Meteoのような認証不要のAPIでは、この手順は不要です。

## 4. APIキーやtokenを登録する

認証が必要なAPIでは、API公式資料に従ってAPIキーやtokenを取得します。

取得した秘密情報を、API詳細画面へ登録して保存します。

- APIキー・token: token欄
- Basic認証: ID欄とPASS欄

秘密情報はJSON、カテゴリファイル、定型文、チャットへ保存しないでください。c-sendはWindows Credential Managerへ保存します。

## 5. カテゴリへAPI項目を追加する

1. 使用するカテゴリを開きます。
2. 一覧の末尾にある「（追加）」を選びます。
3. APIモードを選び、APIとActionを指定します。
4. 本文に実行用プロンプトを入力します。

クリップボードの内容をAPIへ送る場合は、本文に次を含めます。

```text
次の文章を処理してください。

{{clipboard}}
```

5. 保存します。

## 6. 動作確認する

機密情報を含まない短い文章で実行します。

- API項目をクリックして実行する
- 実行中は完了するまで待つ
- 成功した結果はクリップボードへコピーされる
- クリップボードが実行中に変更された場合は、結果保持アイコンから結果をコピーする

## 動かない場合

- 実行不可の場合: API詳細画面でAPIキー、token、ID、PASSを確認する
- API設定が表示されない場合: JSONの保存場所、UTF-8形式、JSON構文を確認する
- 通信エラーの場合: APIのURL、HTTP method、Request JSON、Response JSONを公式資料と照合する
- API仕様が変わった場合: 現在のJSON、同じ版の[API設定JSON仕様](./config-spec.md)、最新の公式資料をAIへ渡して更新を依頼する

対応しているのは、設定JSONで表現できるJSON HTTP APIです。OAuth、署名認証、SSE/WebSocket、multipartなどが必要なAPIは、そのままでは利用できません。
