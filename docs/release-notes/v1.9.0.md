# c-send v1.9.0

## 主な変更

- ネイティブ版でJSON形式のデータファイルを利用できるようになりました。
  - ローカルファイルは拡張子が `.json` の場合にJSONとして扱います。
  - URLはレスポンスの `Content-Type` がJSON系、またはURLパスの末尾が `.json` の場合にJSONとして扱います。
- ローカルJSONの保存時に、PWA版などが利用する `tags` のような追加プロパティを保持します。
- バイナリを導入できないWindows環境向けにHTA版を追加しました。
- iPhone / iPadOS / Androidで利用できるPWA版を追加しました。

## 互換性

- 既存の `setting.ini` と従来の3行1レコード形式のデータファイルは、そのまま利用できます。
- `.json` ではないローカルデータファイルと、JSONを返さないURLは従来形式として扱います。
- 従来形式のデータをJSONとして扱いたい場合だけ、JSON形式のファイルを作成し、`setting.ini` の参照先をそのJSONファイルに変更してください。

詳細は同梱の `docs/data-file-spec.md` を参照してください。
