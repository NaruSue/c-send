# リリースノート

GitHub Release に掲載する説明文の正本を、バージョンごとに管理する。

## ファイル名

`v<major>.<minor>.<patch>.md` とする。

例: `version.h` が `1.9.0` の場合は `v1.9.0.md` を作成する。

## リリース時の扱い

`.github/workflows/release.yml` は `version.h` からバージョンを読み取り、対応するリリースノートが存在する場合だけGitHub Releaseを作成する。

リリースノートには、利用者に影響する変更、互換性に関する注意点、導入・更新時に必要な操作を記載する。コミットメッセージからの自動生成には依存しない。
