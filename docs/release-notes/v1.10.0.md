# c-send ネイティブ版 v1.10.0

## 主な変更

- ネイティブ版のJSONデータファイルを共通JSON形式へ変更しました。
  - `format`、`version`、`createdAt`、`items` を持つルートオブジェクト形式です。
  - `mode` がない項目は `plain` として読み込みます。
  - ネイティブ版で利用しない追加プロパティも、保存時に可能な限り保持します。
- テンプレート機能を追加しました。
  - JSON項目の `mode` を `template` にすると、コピー時にテンプレートを評価します。
  - 日時、クリップボード挿入、行ソート、計算、JSON整形、URIエンコード・デコードに対応します。
  - テンプレート項目は一覧とタスクトレイで `[T]` を付けて表示します。
- 登録・編集画面に `plain text` / `template` の選択を追加しました。

## JSON形式の互換性

- v1.9までの配列をルートとするJSONは読み込まれません。
- JSONファイルは、共通JSON形式へ変換してから利用してください。
- JSON以外の従来の3行1レコード形式は引き続き利用できます。従来形式ではテンプレートを選択できません。

詳しい形式は `docs/data-file-spec.md` と `docs/template-spec.md` を参照してください。
