# c-send ネイティブ版 v2.0.0

## 概要

v2.0.0は、c-sendを定型文コピー用ツールから、設定JSONで外部APIを利用・拡張できるスニペットツールへ発展させる大きな更新です。

API固有の通信処理をアプリ本体へ埋め込まず、API設定JSON、公式資料、AI向けの作成手順を組み合わせて、利用者自身がサービス・Action・プロンプトを追加できる構成にしました。

## API機能

- システムメニューからAPI設定一覧、API詳細、Action詳細を開けます。
- APIごとに基本URL、タイムアウト、認証、固定ヘッダー、Action、JSON request／responseを設定できます。
- 認証なし、API key header/query、Bearer、Basic 認証に対応しました。
- API key、token、ID、PASSはWindows Credential Managerへ保存し、設定JSONへ保存しません。
- GETなど、Request JSONを持たないボディなしActionに対応しました。
- API項目は通常のカテゴリへ追加でき、APIとActionを選んで実行できます。
- 実行、実行中、エラー、実行不可、結果保持を右寄せアイコンで表示します。
- 実行開始後にクリップボードが変更された場合は、結果で自動上書きせず、結果保持アイコンからコピーできます。

## 同梱サンプルと資料

- Gemini、OpenAI、Anthropic Claude API、GitHub REST API、Open-Meteo Weather APIの設定JSONを追加しました。
- Open-Meteoを使う日本語・英語の天気カテゴリサンプルを追加しました。
- 各サービスの認証情報取得・c-send登録ガイドを追加しました。
- API公式資料と仕様書をAIへ渡し、設定JSON・導入手順を生成させるためのプロンプトを追加しました。
- 新しいサービスを追加するための資料テンプレートを追加しました。

## テンプレート・カテゴリ

- `{{clipboard|代替文字列}}`に対応しました。クリップボードが空の場合だけ代替文字列を使えます。
- 拡張子なしの存在しないカテゴリパスは、`.json`を補ってJSON形式のカテゴリとして保存するようにしました。

## テストと配布

- API通信は外部APIキーを使わない汎用モックテストで検証できます。
- Release配布物へ`api/`、`docs/api/`、`samples/`を同梱します。

## 注意事項

- APIキーやtokenを設定JSON、カテゴリファイル、Git、チャットへ保存・投稿しないでください。
- OAuth、署名認証、SSEストリーミング、WebSocket、CLI連携などは、今後必要に応じて汎用機能として追加します。
