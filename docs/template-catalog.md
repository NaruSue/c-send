# テンプレートを探して使う

c-sendには、文章・コマンド・URLなどのサンプルテンプレートが用意されています。

テンプレートの使い方には、2つの方法があります。

| 使い方 | 内容 |
| --- | --- |
| URLから参照 | 公開されている最新の内容をそのまま使う。c-send上では編集できない |
| ダウンロードして追加 | 自分のPCに保存して使う。内容を自由に編集できる |

## URLから参照する

公開テンプレートを、変更せずにそのまま使いたいときの方法です。

1. 使いたいテンプレートのRaw URLをコピーします。
2. c-sendのシステムメニューから「カテゴリ」を開きます。
3. 一覧のいちばん下にある「（追加）」を選びます。
4. カテゴリ名を入力します。
5. 参照先にRaw URLを入力します。
6. 保存します。

例:

```text
https://raw.githubusercontent.com/NaruSue/c-send/master/samples/jp/メール・チャット.json
```

URLで参照したカテゴリには、公開元の変更が反映されます。カテゴリ名には`[URL]`が付き、登録内容は編集できません。

## ダウンロードして追加する

テンプレートを自分用に変更したいときの方法です。

1. テンプレートのJSONファイルをダウンロードします。
2. ダウンロードしたファイルを、分かりやすい場所へ保存します。
3. c-sendのシステムメニューから「カテゴリ」を開きます。
4. 一覧のいちばん下にある「（追加）」を選びます。
5. カテゴリ名を入力します。
6. 参照先に、保存したJSONファイルのパスを入力します。
7. 保存します。

例:

```text
C:\Users\example\Documents\c-send\メール・チャット.json
```

ローカルファイルとして追加したテンプレートは、通常のカテゴリと同じように編集・追加・削除できます。公開元の更新は自動では反映されません。

## 同梱テンプレート

配布物の`samples`フォルダには、次のようなテンプレートがあります。

- `samples\jp\メール・チャット.json`
- `samples\jp\挨拶.json`
- `samples\jp\Git.json`
- `samples\jp\SQL.json`
- `samples\jp\PowerShell.json`
- `samples\jp\Windowsコマンド.json`
- `samples\jp\Markdown.json`
- `samples\jp\HTML.json`
- `samples\jp\Gemini API.json`

同梱ファイルを使う場合は、`csend.exe`と同じ場所にある`samples`フォルダのファイルをカテゴリの参照先に指定します。

## どちらを選ぶか

- 最新の内容を確認しながら使いたい: URLから参照
- 自分の文章やコマンドを追加したい: ダウンロードして追加
- 公開テンプレートを元に自分用のカテゴリを作りたい: ダウンロードして追加

URLで参照したカテゴリは読み取り専用です。編集したい場合は、ファイルをダウンロードしてローカルファイルとして追加してください。
