# c-send HTA版 設計書

Windows標準の `mshta.exe` で動作する、c-sendの軽量版を定義する。

HTA版の目的は、実行ファイル（`.exe`）を配布・インストールできないセキュリティの厳しい環境でも、ファイルを配置するだけでc-sendを利用できるようにすることである。

## 基本方針

- バイナリのインストールを不要にする
- レジストリを変更しない
- `c-send.hta` とデータファイルをフォルダ単位で配置して使用する
- ネイティブ版の全機能を再現せず、定型文の表示とコピーを中心にする
- 初期版は単一カテゴリとする
- 設定画面は作らず、設定ファイルを直接編集する
- JSONデータ形式は、ネイティブ版・PWA版と共通の [共通JSONデータ形式仕様](../../../docs/data-file-spec.md) を参照する

## バージョン管理

HTA版はネイティブ版と機能および配布形態が異なるため、HTA版固有のバージョンを持つ。

- バージョンは `c-send.hta` 内の `APP_VERSION` を唯一の管理元とする
- タイトルバーには `c-send HTA v{APP_VERSION}` と表示する
- `default.json` または `setting.ini` の形式・キー・意味を変更する場合は、メジャーバージョンを上げる
- それ以外の機能追加・修正では、マイナーバージョンを上げる
- 初期バージョンは `1.0` とする

## ファイル構成

`scripts-ver/hta/` をHTA版の唯一の実体および配布単位とする。HTAはソースコード自体を実行するため、開発用とリリース用のファイルを二重に管理しない。

リリース時はこのフォルダの内容をそのままZIP化するなどして配布する。常設の `release` や `dist` フォルダは作成しない。

```text
scripts-ver/hta/
├─ c-send.hta
├─ c-send.ico
├─ default.json
├─ setting.ini
└─ docs/
   └─ design.md
```

### `c-send.hta`

HTA本体。画面表示、データ読込、追加・編集・削除、クリップボードコピーを実装する。

### `c-send.ico`

HTAのウィンドウおよびタスクバーに表示するアイコン。同じフォルダに配置する。

### `default.json`

単一カテゴリの定型文データを保存する。UTF-8の共通JSON形式とする。形式の詳細は [共通JSONデータ形式仕様](../../../docs/data-file-spec.md) に従う。

HTA版は、カテゴリごとにHTA本体とJSONを同じディレクトリへ配置して使用できる。

```text
仕事/
├─ c-send.hta
└─ default.json
```

- `default.json` はHTA本体と同じディレクトリから相対パスで読み込む
- `categoryName` が設定されている場合は、画面上にカテゴリ名として表示する
- `categoryName` がない場合は、配置ディレクトリ名またはファイル名を表示用の代替値とする
- カテゴリごとにJSONファイルが分かれるため、あるカテゴリの編集結果が別カテゴリのJSONを上書きしない

```json
{
  "format": "c-send-pwa-backup",
  "version": 1,
  "createdAt": "2026-07-27T00:00:00.000Z",
  "categoryName": "仕事",
  "items": [
    {
      "name": "Git Status",
      "value": "git status",
      "type": 0,
      "mode": "plain"
    }
  ]
}
```

- `default.json` のルートは本仕様のオブジェクトとする
- 定型文の項目、保存時の検証、追加プロパティの保持は共通仕様に従う
- 複数行の本文を許可する
- データ件数の上限は共通仕様に従い100件とする

### 一覧の種別表示

一覧では、`mode` に応じて項目名の先頭に種別表示を付ける。

- `plain`：種別表示なし
- `template`：`[T]` を付ける
- `counter`：`[C]` を付ける

種別表示は表示上の接頭辞であり、`name` の保存値には含めない。

### 追加・編集画面

- 本文入力欄の下に、`plain text` と `template` のラジオボタンを表示する
- 新規追加時は `plain text` を既定選択とする
- 編集時は、保存されている `mode` に応じて選択状態を復元する
- `counter` は当面ラジオボタンの選択肢として表示せず、保留とする

### `setting.ini`

ウィンドウ位置とサイズだけを保存する。データ本体やカテゴリ情報は保存しない。

```ini
[Window]
left=100
top=100
width=500
height=700
```

- `left`：ウィンドウ左端の画面座標
- `top`：ウィンドウ上端の画面座標
- `width`：ウィンドウ幅
- `height`：ウィンドウ高さ
- 値が不正、または画面外の場合は既定値を使用する
- 起動時に位置とサイズを復元する
- 終了時に通常状態の位置とサイズを保存する

## 初期版の機能

- `default.json` の読込・保存
- 定型文一覧の表示
- 一覧項目の `mode` に応じた種別表示
- 一覧項目のシングルクリックによるクリップボードコピー
- `plain text` / `template` の選択
- 定型文の追加
- 定型文の編集
- 定型文の削除
- 複数行テキストの入力
- ウィンドウサイズ変更
- ウィンドウ位置・サイズの保存と復元
- HTAアイコンの表示

## 操作

- 一覧をクリック：本文をクリップボードへコピー
- 右クリック：コンテキストメニューを表示
  - `add`：定型文を追加
  - `edit`：選択中の定型文を編集
  - `del`：選択中の定型文を削除
- 追加・編集・削除の完了時に `default.json` を保存する

## URL取込

HTAはURLからのテキスト取得を実装しやすいため、将来の拡張候補とする。

初期版では必須機能とせず、追加する場合は次の仕様とする。

- URLを指定してJSONまたはテキストデータを読み込む
- JSONを読み込む場合は、[共通JSONデータ形式仕様](../../../docs/data-file-spec.md) に適合するJSONだけを受け付ける
- URLから読み込んだデータは読み取り専用として扱う
- ローカルの `default.json` は通常の編集・保存対象とする
- 通信失敗、認証、プロキシ、TLSなどの環境差を考慮する

## 初期版で実装しない機能

- 複数カテゴリおよびカテゴリ管理画面
- タスクトレイ常駐
- 常に手前表示
- 単一起動制御
- Windows toast通知
- ネイティブ版の3行形式データファイルとの互換
- ネイティブ版の `setting.ini` 全項目との互換

## 注意事項

- HTAは環境によって `mshta.exe` 自体がセキュリティポリシーで禁止されている場合がある
- `default.json` はアプリと同じフォルダに置き、相対パスで扱う
- 保存失敗時はデータを失わないよう、エラーメッセージを表示する
- JSONの形式不正時は空データとして上書きせず、読込エラーとして扱う
