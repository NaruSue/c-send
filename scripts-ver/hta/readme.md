# c-send HTA版

Windows 標準の `mshta.exe` で動く、c-send の HTA 版です。

実行ファイルの配布やインストールが難しい、セキュリティの厳しい環境でも使えることを目的にしています。`c-send.hta` とデータファイルを同じフォルダに置くだけで動作します。

## できること

- 定型文の一覧表示
- 一覧をクリックして本文をクリップボードへコピー
- 定型文の追加
- 定型文の編集
- 定型文の削除
- ウィンドウ位置とサイズの保存

ネイティブ版と比べると、HTA 版は機能を絞っています。

- 単一カテゴリのみ
- カテゴリ管理画面なし
- 設定画面なし
- URL 取り込みは将来拡張候補

## 導入方法

1. `scripts-ver/hta/` フォルダをそのまま配置します。
2. `c-send.hta` をダブルクリックして起動します。
3. 必要に応じて `default.json` と `setting.ini` を同じフォルダに置いて使います。

`default.json` がない場合は起動時に自動作成されます。`setting.ini` がない場合は既定値で起動し、終了時に保存されます。

## 使い方

### 一覧からコピーする

一覧の項目をクリックすると、本文がそのままクリップボードへコピーされます。コピーできると右下に「コピー完了」と表示されます。

### 追加する

1. 一覧を右クリックします。
2. メニューから「追加」を選びます。
3. タイトルと本文を入力して保存します。

### 編集する

1. 編集したい項目を選択します。
2. 一覧を右クリックします。
3. メニューから「編集」を選びます。
4. タイトルや本文を修正して保存します。

### 削除する

1. 削除したい項目を選択します。
2. 一覧を右クリックします。
3. メニューから「削除」を選びます。
4. 確認後に削除されます。

## ファイル構成

`scripts-ver/hta/` をそのまま配布単位として使います。開発用と配布用で別フォルダを作らず、このフォルダをまとめて渡します。

```text
scripts-ver/hta/
├─ c-send.hta
├─ c-send.ico
├─ default.json
├─ setting.ini
└─ docs/
   └─ design.md
```

## 設定ファイル

### `default.json`

定型文のデータ本体です。UTF-8 の JSON 形式で保存します。

1件ごとに、次の値を持ちます。

- `name`: 一覧に表示するタイトル
- `value`: コピーする本文
- `type`: データ種別。初期版では `0` のみ

例:

```json
[
  {
    "name": "Git Status",
    "value": "git status",
    "type": 0
  }
]
```

### `setting.ini`

ウィンドウの位置とサイズだけを保存します。

```ini
[Window]
left=100
top=100
width=500
height=700
```

## 補足

- HTA 版は Windows 専用です
- `mshta.exe` が禁止されている環境では起動できません
- データ件数は 100 件までです
- 複数行の本文に対応しています
- アイコンは `c-send.ico` を使います
